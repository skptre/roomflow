# Project index

Before searching the codebase, read `docs/INDEX.md`: a lookup table from "looking for…" to the file that has it.
For what each file contains (types and functions), use `docs/ARCHITECTURE.md`. Only search when neither answers.

Keep both current: a new file, module, or major concern gets a row in `docs/INDEX.md` and an entry in
`docs/ARCHITECTURE.md` in the same change.
